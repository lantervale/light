How light does it

Translate in the page, on the device

This page asks the browser's own language model to name the language of a text and to translate it, through the Translator and Language Detector APIs. Nothing is sent anywhere: the page has no server to send to.

… Asking the browser…

What the browser can do

Translator.availability() says whether the browser translates from one language into another; LanguageDetector.availability() whether it names languages. Neither starts or downloads anything.

Try it

detect() names the language of what you type, most likely first; translateStreaming() translates it, the words showing as they come; measureInputUsage() says how much of inputQuota, the most one call takes, the text uses.

Input usage: not measured yet

The calls, one by one

  • Translator.create({sourceLanguage, targetLanguage}) gives a translator for one pair; light never downloads anything for a page, so it either has one at once or refuses.
  • translator.translate(text) resolves with the whole translation, as plain text.
  • translator.translateStreaming(text) gives a stream of the translation's pieces, read with for await.
  • LanguageDetector.create() then detector.detect(text) list the languages the text may be in, ending with "und", the unknown.
  • destroy() ends a translator or a detector, and an AbortSignal stops any call.
